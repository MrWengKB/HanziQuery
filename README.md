【目的】<br>
协助教师出题、教学，有兴趣的家长也可以用来考查孩子的学习进度。

【功能】<br>
目前有一到三年级新教材的字。按照一年出一个年级新教材的速度，还需要三年才能做完。<br>
可以通过不同的条件（比如查询同拼音的字）以及条件组合（比如一年级+左右结构+9画的字）来查找识读字。<br>
点击小字卡可以显示大字卡，有年级、课次、读音（包括常见多音字）、结构、总笔画数等。<br>
如果该字有已确定的甲骨文，也会有甲骨文显示按钮。<br>
点击汉语拼音时会播放音频。

【应用】<br>
可以访问网页使用，也可以安装应用，包括安卓的APK和各系统通用的PWA。

【实现方式】<br>
hanzilist是一个包含汉字详情的CSV。网页使用JS读取这个CSV，并渲染每张字卡。<br>
汉字详情是使用Claude交叉比对权威字典网站生成，并经人工检查。因为最后是人工检查，所以可能会有错误。<br>
甲骨文使用免费的方正甲骨文字体。每次加入新字，会使用PY检测某字是否存在于这个字体里，并在上述CSV里标记。
发音音频来自 https://github.com/hugolpz/audio-cmn/ (CC-by-sa) 但删除了标准汉语不存在的音节。轻声作第一声处理。
