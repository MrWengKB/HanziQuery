识读字查询 隐私政策

生效日期：2026 年 11 月 26 日

我们不收集任何个人信息

小学华文识读字查询系统（网页版和安卓 App，下称「识读字查询」）不需要注册或登录，不收集、不上传、不出售、也不与任何人分享你的个人信息。App 里没有广告，也没有第三方统计或追踪工具。

数据只保存在你的设备上

字表、字体和读音音频都打包在 App 里，查询、筛选、搜索全部在你的设备上完成，不会把你查询的内容发送到任何服务器。网页版可能会在浏览器里保存少量设置或离线缓存，清除浏览器数据或卸载 App 就会一并删除。

网络使用

识读字查询可以完全离线使用。网页版第一次打开时会从网站下载所需文件并存在设备上，以便离线使用。直接下载安装的安卓 APK 版本在启动时会向 GitHub 查询是否有新版本，这个请求不包含任何个人信息，是否下载安装由你决定。Google Play 版本不会进行这项检查。

点击 README 里的外部链接时，会用你的浏览器打开该网站，那个网站的隐私做法不在本政策范围内。

儿童隐私

识读字查询主要给教师和家长使用。因为我们不收集任何信息，所以也不会收集儿童的个人信息。

权限

安卓 App 只使用「网络」权限（用于上述的更新检查）。不使用相机、麦克风、位置、通讯录等任何其他权限。

政策变更与联系方式

如果这份政策有变更，会更新本页面和上面的生效日期。有任何问题，请到 GitHub Issues 留言。

Privacy Policy – HanziQuery

Effective: 26 November 2026

We collect no personal data. HanziQuery (web and Android) requires no account or sign-in, contains no ads, analytics or tracking, and does not collect, upload, sell or share any personal information.

Everything stays on your device. The character list, fonts and audio are bundled with the app. All searching and filtering happens on your device; nothing you look up is sent to any server. The web version may keep small settings and an offline cache in your browser, which are removed when you clear browser data or uninstall the app.

Network. The app works fully offline. The directly downloaded APK checks GitHub for a newer version at launch; this request contains no personal information, and you decide whether to install the update. The Google Play version does not perform this check.

Children. HanziQuery is intended for teachers and parents. As no data is collected, no data from children is collected.

Permissions. The Android app uses only the Internet permission (for the update check above).

Contact. Please open an issue at GitHub Issues.
